# B 車道幾何 + 事後 crossing IL 重評分

## 問題
v2 的 B 配置（B_db_placeholder）繞線時 crossing loss = 0 dB。
若把 crossing 的插入損耗算進去，Waksman 相對 padded Beneš 是否仍有優勢？

## 方法（精確，非估計）
1. 載入 v2 B 車道每案的 `routing_result.pkl`（既有幾何，不重繞）
2. 枚舉全部 I→O 路徑，計算各路徑的損耗分量（長度/彎/crossing/MRR）——這些**與係數無關**
3. 對每個 crossing loss 值重新排序、**重新尋找 worst path**（argmax 會隨係數改變！）
4. 可實現性認證（隨機見證，20000 tries）跨係數共用快取
5. 回報區間：lower = 首個認證可實現的路徑；upper = 全路徑最大值（忽略可實現性）
   真值必在 [lower, upper]。判定只在一方 upper < 另一方 lower 時才算 definitive。

驗證：xloss=0 的結果與 v2 窮舉基準完全吻合（如 waksman n8 = 4.927、benes n8 = 4.524）。

## 結論
1. **八度週期的勝負格局對 crossing loss 穩健**——贏家在所有係數值下幾乎不變（唯一例外 N=4 是 ±0.1 dB 的平手，符號會翻）。
2. **在核心窗口 N=9–11，加入 crossing IL 會 *放大* Waksman 的優勢**（N=9: +1.17 → +3.48 dB），
   因為 Waksman 的 worst path crossing 數顯著少於 Beneš（20 vs 33）。
3. **N=12 是例外**：優勢隨 crossing loss *縮小*（+0.62 → +0.41），因為 Waksman 的 crossing 數
   已追平 Beneš（36 vs 33–35）——這是下一個八度交叉點逼近的前兆。
4. **N=7,8（八度上半）加入 crossing IL 會讓 Waksman 輸更多**（−0.46 → −1.21 dB），
   因為該區間 Waksman crossing 較多（21 vs 13–18）。

## 重要限制
- 這是**事後重評分**：兩個拓撲的幾何都是在 crossing=0 下最佳化的，誰都沒有為了閃 crossing 而繞路。
  若改為「帶著 crossing 成本重新繞線」（= C 配置），結論不同：N=7,8 Beneš 贏更多，
  且 Waksman 在 N≥10 出現繞線失敗。兩種讀法回答不同問題：
  - 本表 = 「固定 fabric，用寫實係數評估」
  - C 配置 = 「為寫實係數重新最佳化」
- worst path 會隨係數改變（N=10 的 21→30 個 crossing），所以「WIL + L×原 worst_x」的樸素加法會**低估**。
